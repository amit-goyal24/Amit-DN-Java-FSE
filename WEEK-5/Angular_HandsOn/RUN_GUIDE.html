Student Course Portal

How to run, use, test, and troubleshoot the Angular Hands-On project.

What this portal does

Home dashboard
Shows portal statistics, a live search field, and an enrollment action.
Courses board
Loads courses, displays cards, course status, credits, hover highlight, and detail navigation.
Enrollment
Provides both template-driven and reactive forms with validation.
State and API
Uses HttpClient, RxJS, interceptors, and NgRx state for courses and enrollment IDs.

How to run it

Open PowerShell in the project directory and install packages once:

cd C:\Users\Lenovo\Harsh-DN-JavaFSE\Angular_HandsOn
npm install

Start the Angular application:

npm start

Open http://localhost:4200 in your browser.

Important: Keep this terminal running while using the website. Stop it with Ctrl + C.

Start the mock API (recommended)

Open a second PowerShell window. JSON Server reads db.json and provides the course API at port 3000.

cd C:\Users\Lenovo\Harsh-DN-JavaFSE\Angular_HandsOn
npx json-server --watch db.json --port 3000

Then visit http://localhost:3000/courses to see the raw API data. If JSON Server is not running, the app uses its sample-course fallback data.

What to do in the portal

  1. Home: type into the search box and click Enroll Now to see binding and event handling.
  2. Courses: wait for data, hover over cards, expand details, enroll/unenroll, and click a card to open its detail page.
  3. Enroll: fill all fields correctly; the submit button stays disabled until valid.
  4. Enroll Reactive: try leaving the page after changing a value; the unsaved-changes confirmation should appear.
  5. Profile: this route is protected by the mock auth guard. The current demo login value is true.

How errors are handled and defined

An error means the application cannot compile, cannot contact its API, or receives invalid data. Read the first red error line; it normally contains the file and line number.

Error / symptomMeaningFix
NG2008: Could not find template fileThe component's templateUrl points to a missing/renamed HTML file.Ensure the named file exists beside the component, then stop and restart npm start.
Failed to load courses or network errorJSON Server is off, API port is wrong, or request failed.Run the JSON Server command above and confirm http://localhost:3000/courses opens.
Cannot find moduleRequired npm packages are absent.Run npm install, then restart Angular.
Browser shows an old error after a code fixThe Angular dev server has stale compilation state.Press Ctrl + C, run npm start again, and hard refresh with Ctrl + Shift + R.
Port 4200 is already in useAnother Angular server is already running.Use the existing tab/server, stop the old process, or accept the alternate port Angular offers.
Form does not submitOne or more validation rules are not satisfied.Read the field message, fill every required field, use a valid email, and tick the terms checkbox.

Verification commands

# Production build
npm run build

# Unit tests in Chrome Headless
npx ng test --watch=false --browsers=ChromeHeadless

A successful build produces the deployable application inside dist/Angular_HandsOn.
